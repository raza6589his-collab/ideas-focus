# 🎯 برنامه ایده‌ها و تمرکز (Focus & Idea Engine)
## نسخه وب و نسخه بومی دسکتاپ ویندوز (Web & Windows Desktop Editions)

یک برنامه شخصی و پایدار بر پایه پایتون، دیتابیس SQLite (با حالت WAL) و رابط کاربری سرمقاله‌ای و فارسی برای تخلیه شناختی و تمرکز عمیق تک‌کاره:
$$\text{Capture quickly} \longrightarrow \text{Prioritize consciously} \longrightarrow \text{Focus on one} \longrightarrow \text{Complete} \longrightarrow \text{Archive}$$

این نرم‌افزار با ابزارهای شلوغ مدیریت پروژه یا چک‌لیست‌های روزمره تفاوت بنیادین دارد؛ هدف آن این است که هر ایده‌ای را در لحظه خطور به ذهن با حداقل تعامل ثبت کنید، آن را هوشمندانه اولویت‌بندی کنید، بدون حواس‌پرتی روی یک ایده در کانون تمرکز کار کنید و پس از اتمام، آن را به بایگانی بسپارید.

---

## 🌟 قابلیت‌های اصلی محصول

1. **ثبت سریع ایده (Quick Idea Capture)**:
   - همیشه آماده در بالای صفحه با عبارت «چه چیزی الان توی ذهنت هست؟».
   - تنها وارد کردن عنوان الزامی است؛ فشردن `Enter` یا میانبر `Ctrl + N` ایده را در کسری از ثانیه ثبت کرده و کادر را برای ایده بعدی آماده نگه می‌دارد.
2. **سیستم اولویت‌بندی سه‌سطحی (Priority Matrix)**:
   - 🔴 **زیاد (High)**: نیازمند اقدام فوری؛ همیشه در صدر صف و بالاترین اولویت برای کانون تمرکز.
   - 🟡 **متوسط (Medium)**: اولویت دوم.
   - 🟢 **کم (Low)**: ایده‌های پس‌زمینه و بدون تعجیل.
   - تغییر مستقیم و سریع اولویت از روی سطر ایده با یک کلیک و مرتب‌سازی آنی.
3. **کانون تمرکز (Focus Sanctuary)**:
   - محیط ایزوله و خلوت با فضای سفید تعمدی و بدون عناصر پرت‌کننده حواس.
   - انتخاب هوشمند تک‌ایده در لحظه طبق الگوریتم:
     $$\text{Pinned Idea} \longrightarrow \text{Oldest High} \longrightarrow \text{Oldest Medium} \longrightarrow \text{Oldest Low}$$
   - امکان سنجاق کردن دستی یک ایده به عنوان کانون تمرکز (حداکثر ۱ ایده در هر لحظه).
   - تکمیل ایده مستقیماً از داخل فوکوس مود و سوئیچ خودکار به ایده بعدی.
4. **تکمیل و سیستم Undo ۵ ثانیه‌ای**:
   - انیمیشن ملایم Fade-out (بدون انیمیشن‌های شلوغ یا کانفتی).
   - نمایش نوار اعلان موقت ۵ ثانیه‌ای همراه با خط تایمر و دکمه `Undo`؛ در صورت لغو، وضعیت ایده در دیتابیس با تاریخ ایجاد اولیه احیا می‌شود.
5. **بایگانی انجام‌شده (Completed Archive)**:
   - ثبت و نمایش تاریخ و ساعت دقیق تکمیل.
   - امکان بازگردانی (Restore) به فهرست فعال یا حذف دائمی با پنجره تأیید.
6. **جستجوی Real-time**:
   - با میانبر `Ctrl + K` در عنوان و توضیحات ایده‌ها.
7. **پایداری صددرصد در SQLite (WAL Mode)**:
   - داده‌ها بلافاصله در دیسک ذخیره می‌شوند؛ ریفرش، بستن برنامه یا خاموشی سیستم آسیبی به داده‌ها نمی‌زند.
8. **زبان بصری سرمقاله‌ای و تم تیره/روشن**:
   - راست‌چین (RTL)، تایپوگرافی خوانای وزیرمتن، بدون اموجی در کنترل‌های رابط کاربری (آیکون‌های برداری SVG یکپارچه).

## 💻 روش‌های اجرا (Execution Modes)

برنامه دارای **یک هسته منطقی، یک پایگاه‌داده و دو روش اجرای کاملاً مستقل** است:

### ۱. نسخه بومی دسکتاپ ویندوز (Windows Desktop Edition - توصیه‌شده)
اجرا در یک پنجره نرم‌افزاری مستقل و بومی ویندوز بر پایه **PySide6 و Qt WebEngine** بدون نوار آدرس، تب‌ها یا المان‌های مرورگر:

- **روش سریع (دابل‌کلیک)**: روی فایل [`run_desktop.bat`](run_desktop.bat) دو بار کلیک کنید.
- **روش خط فرمان**:
  ```powershell
  python desktop_app.py
  ```
- **اجرای فایل مستقل کامپایل‌شده (EXE)**:
  فایل اجرایی در مسیر زیر ساخته شده و بدون نیاز به نصب هیچ ابزاری مستقیماً اجرا می‌شود:
  ```text
  dist\IdeasFocus\IdeasFocus.exe
  ```

### ۲. نسخه وب محلی (Local Web Edition)
اجرا در مرورگر سیستم‌عامل (Chrome، Edge، Firefox و غیره):

- **روش سریع (دابل‌کلیک)**: روی فایل [`run.bat`](run.bat) دو بار کلیک کنید.
- **روش خط فرمان**:
  ```powershell
  python app.py
  ```
  سپس مرورگر خود را باز کرده و به آدرس `http://127.0.0.1:5000/` بروید.

## 📦 نحوه ساخت و کامپایل فایل اجرایی ویندوز (Build Desktop EXE)

برای ساخت مجدد پکیج اجرایی ویندوز (`IdeasFocus.exe`) به همراه تمامی وابستگی‌های Qt WebEngine و قالب‌ها:

- **روش آسان**: روی فایل [`build_desktop.bat`](build_desktop.bat) دابل‌کلیک کنید.
- **روش دستی با PyInstaller**:
  ```powershell
  pyinstaller --clean -y IdeasFocus.spec
  ```
خروجی نهایی در پوشه `dist\IdeasFocus\` قرار می‌گیرد.

## 💿 فایل نصبی ویندوز (Windows Setup Installer - Inno Setup 7)

برای توزیع و نصب استاندارد برنامه در سیستم‌عامل ویندوز (مانند تمام نرم‌افزارهای استاندارد ویندوزی):

- **فایل نصبی آماده**:
  ```text
  installer\IdeasFocus_Setup_v1.0.0.exe
  ```
  با اجرای این فایل، برنامه با ویزارد مدرن نصب شده، میانبرهای منوی استارت و دسکتاپ ایجاد شده و در لیست برنامه‌های ویندوز (Installed Apps / Control Panel) به همراه قابلیت حذف خودکار (Uninstaller) قرار می‌گیرد.

- **ساخت مجدد فایل نصبی (Build Installer)**:
  - با دابل‌کلیک روی [`packaging/build_installer.bat`](packaging/build_installer.bat)
  - یا از طریق خط فرمان:
    ```powershell
    & "C:\Program Files\Inno Setup 7\ISCC.exe" "packaging\installer.iss"
    ```
  این دستور پکیج کامل را با الگوریتم فشرده‌سازی مدرن LZMA2 کامپایل و در پوشه `installer\` قرار می‌دهد.

## 📂 ساختار فایل‌های پروژه (Modular Architecture)

```text
Ideas management/
│
├── run_desktop.bat          # اجرای نسخه دسکتاپ ویندوز (دابل‌کلیک)
├── run_web.bat              # اجرای نسخه وب محلی (دابل‌کلیک)
│
├── app.py                   # هسته وب‌سرور Flask و مدیریت APIها
├── database.py              # لایه داده و بیزینس‌لاجیک SQLite (WAL Mode)
├── desktop_app.py           # کلاینت بومی پنجره دسکتاپ ویندوز (PySide6)
│
├── desktop/                 # دارایی‌های آیکون رسمی برنامه (.ico و .png)
├── templates/               # قالب‌های HTML برنامه (index.html)
├── static/                  # فایل‌های CSS و JS رابط کاربری
│
├── tests/                   # بسته آزمون‌های خودکار
│   ├── test_suite.py        # آزمون‌های مدل داده، منطق فوکوس و استرس ۱۰۰ ایده
│   ├── test_api.py          # آزمون‌های اندپوینت‌های RESTful
│   └── test_packaged_exe.py # آزمون فایل اجرایی کامپایل‌شده
│
├── packaging/               # ابزارها و اسکریپت‌های بسته‌بندی و بیلد
│   ├── IdeasFocus.spec      # پیکربندی رسمی PyInstaller
│   ├── installer.iss        # اسکریپت کامپایلر Inno Setup 7
│   ├── build_desktop.bat    # اسکریپت بیلد فایل اجرایی دسکتاپ
│   └── build_installer.bat  # اسکریپت ساخت فایل نصبی Setup.exe
│
├── dist/IdeasFocus/         # خروجی پکیج اجرایی مستقل (IdeasFocus.exe)
├── installer/               # خروجی فایل نصبی ویزاردی (IdeasFocus_Setup_v1.0.0.exe)
│
├── requirements.txt         # نیازمندی‌های کامل پکیج‌های پایتونی
├── README.md                # مستندات و راهنمای کامل برنامه
└── .gitignore               # قوانین کنترل نسخه Git
```

## 💾 محل ذخیره و پشتیبان‌گیری از دیتابیس (Database Location & Backup)

پایگاه‌داده برنامه بر پایه SQLite با ساختار پایدار پیاده‌سازی شده است:

1. **در حالت توسعه (Development)**:
   - فایل دیتابیس در همان پوشه پروژه با نام `ideas.db` ذخیره می‌شود.
2. **در حالت فایل اجرایی بسته‌بندی‌شده (Packaged EXE)**:
   - برای تضمین امنیت و جلوگیری از پاک شدن داده‌ها در پوشه موقت سیستم، فایل دیتابیس در مسیر دائمی کاربر ذخیره می‌گردد:
     `%APPDATA%\IdeasFocusApp\ideas.db`
     (معمولاً معادل `C:\Users\<نام‌کاربر>\AppData\Roaming\IdeasFocusApp\ideas.db`)

### تهیه نسخه پشتیبان (Backup):
برای بکاپ‌گیری کافی است در هر زمان یک کپی از فایل `ideas.db` بردارید:
```powershell
copy ideas.db ideas_backup.db
```

## ⌨️ میانبرهای صفحه‌کلید (Keyboard Shortcuts)

| میانبر | عملکرد |
| :--- | :--- |
| **`Ctrl + N`** | فوکوس آنی روی کادر ثبت ایده جدید |
| **`Ctrl + K`** | فوکوس روی کادر جستجو |
| **`Ctrl + F`** | جابجایی سریع بین فهرست ایده‌ها و کانون تمرکز (Focus Mode) |
| **`Enter`** (در کادر ثبت سریع) | ثبت ایده و آماده‌سازی برای ایده بعدی |
| **`Escape`** | بستن پنجره‌های باز، مودال‌ها، یا لغو فوکوس |
| **`F5`** (در دسکتاپ) | بارگذاری مجدد پنجره برنامه |

## 🛠️ عیب‌یابی (Troubleshooting)

- **خطای پایتون در فایل‌های bat**:
  پایتون ۳ را از سایت رسمی [python.org](https://www.python.org/) نصب کنید و تیک گزینه `Add python.exe to PATH` را بزنید.
- **اجرای هم‌زمان دسکتاپ و وب**:
  برنامه دسکتاپ به طور خودکار پورت‌های آزاد را تشخیص می‌دهد و تداخلی با باز بودن پورت‌های دیگر سیستم ایجاد نمی‌کند.
